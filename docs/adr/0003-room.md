# ADR 0003: Room is the only durable store

## Status

Accepted.

## Context

Emergency and crash-loop flags must survive process death. A second store (DataStore, files, SharedPreferences) would fork the source of truth.

## Decision

Room `cenix.db` v1 is `launcher_metadata` (`1.json`, identityHash `4245c49e2ef1c5f9cb6826b6784234ad`). v2 adds `workspace_items` via `MIGRATION_1_2`. No destructive fallback. Open failure → memory store + emergency. User “reset” deletes the DB file. `allowBackup=false`. No silent delete on startup.

## Consequences

`CrashLoopGuard` persists through `RoomStartupStore`. Process death keeps `emergency=true`. Catalog stays live from `LauncherApps`, not Room.
