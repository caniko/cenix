# ADR 0003: Room is the only durable store

## Status

Accepted.

## Context

Emergency and crash-loop flags must survive process death. A second store (DataStore, files, SharedPreferences) would fork the source of truth.

## Decision

Room `cenix.db` is at v9 with additive, explicit migrations and a bounded restore journal. No destructive fallback. Open failure → memory store + emergency. User “reset” deletes the DB and any pending transport artifact. A custom `BackupAgent` backs up one canonical JSON file; extraction rules exclude Room itself. No silent database delete occurs on startup.

## Consequences

`CrashLoopGuard` persists through `RoomStartupStore`. Process death keeps `emergency=true`. Catalog stays live from `LauncherApps`, not Room.
