# ADR 0012: Native workspace drag

## Status

Accepted.

## Context

Long-press unpin cannot move a pin. Drag is public SDK (`View.startDragAndDrop`).

## Decision

Long-press a pinned cell starts a system drag. Drop on an empty workspace or hotseat cell moves. Release on the same cell or drop off-grid unpins. Occupied cells reject. All Apps long-press still pins or docks. No swap, no folders, no All Apps drag.

## Consequences

Emulator unpin is drag-off, not long-press. Folders stay out.
